# DTA301-NYC-Airbnb-Analysis

Data Analysis project exploring the New York City Airbnb market in 2019. 
This repository contains the Project Report for Phase 1 (Discovery) & Phase 2 (Data Preparation).

## Contents
- **AB_NYC_2019.csv**: The raw dataset used for analysis.
- **Project_Report_Phase_1_2.docx**: The finalized project report.
- **create_report.py**: Python script used to generate the report.
